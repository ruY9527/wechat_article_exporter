# 小红书 + 抖音 推广素材与草稿自动化

微信公众号文章导出助手的推广内容生产，以及把内容自动填进两个平台草稿箱的可复用工具。

## 快速开始

```bash
# 生成 5 张推广图（改文案后跑）
python render.py

# 小红书草稿
python xhs_publish.py

# 抖音草稿
python douyin_publish.py
```

两个脚本都**只存草稿，永不点发布**。

## 两个平台的差异（重要）

| 项目 | 小红书 | 抖音 |
| :--- | :--- | :--- |
| 发布页路由 | `/publish/publish?target=image` | `/content/post/image`（**不是** `/upload`） |
| 标题框 | contenteditable，y≈405 | input，y≈320（y≈210 是「快速填写」，会点错） |
| 标题上限 | 20 字 | 20 字 |
| 正文上限 | 1000 字（含标签） | 1000 字（含标签） |
| 上传入口 | 空态大按钮 (790,500) | 右侧区域 (1758,480) |
| 保存按钮 | (1066,1342) 直接可见 | (1101,1300)，**必须先按两次 End 滚到底** |
| 保存后表现 | 顶部绿色「保存成功」 | 跳回上传页 + 「你还有上次未发布的图文」 |
| 标签写法 | `#标签` + 回车选中 | `#标签` + 回车选中 |

## 换环境必做

坐标是硬编码的，窗口状态变了就要重标：

1. 最大化窗口（`xhs_config.py` / `douyin_config.py` 首行已设 DPI 感知）
2. 截图 → 读图确认各元素纵向位置
3. 改对应 config 里的坐标常量

标定方法见 `PLAYBOOK.md` §3。

## 前提

- Chrome 已登录对应平台的创作服务平台
- 图片文件名与 config 里 `IMAGES` 一致
- 正文控制在 950 字内（1000 上限，标签占字数；抖音标题另算 20 字）
