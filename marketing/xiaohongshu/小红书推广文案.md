## 二、正文（主推版，可直接复制发布）

公众号好文，一键变成能存一辈子的文件 📎

先说一个我憋了很久的事。

我收藏夹里有几百篇公众号文章。技术教程、行业分析、别人的读书笔记。
当时都觉得「这个以后一定用得上」。

结果这两年回头翻，一半打不开了。
作者删号的、团队解散的、图床过期的、被判定违规下架的……
就算页面还在，图也全变成灰框——微信图床有防盗链，换个环境打开就是一片空白。

最讽刺的是：**我收藏的时候以为自己留住了它，其实只是留了一个链接。**

后来我自己写了个 Chrome 扩展，把这件事彻底解决掉。

---

### 它做什么

打开任意一篇公众号文章，点一下扩展图标，选一种格式：

**① Markdown + 图片 ZIP（最完整）**
导出一个 `.zip`，解压后是 `文章标题.md` + `images/` 文件夹。
`.md` 里所有图片链接都已经重写成 `./images/img_001.png`，图片是真的下载到你本地了。
拖进 Typora / Obsidian / VS Code 就能看。**断网也能正常渲染**——这一点我专门测过。

**② 纯 `.md` 文件（最轻）**
不下载图片，保留原图链接。适合只想要文字的摘录，体积几 KB。

**③ 高保真 PDF（最好读）**
图片全量预热、打印样式注入、分层分页控制。文字是矢量的——可以选中、可以搜索、可以复制、可以扔进任何笔记软件做全文检索。

---

### 为什么我自己用得上

说三个真实场景：

- 看到一篇讲得很透的行业分析，**先导成 md 存进 Obsidian**，跟自己的笔记放在一起，以后按关键词就能搜到。
- 学一个新东西，把三五篇教程**批量导成 PDF 归档**，断网在高铁上翻。
- 公司的公众号内容要沉淀成内部资料，**md 交给同事继续编辑**，不用再一段段复制粘贴。

---

### 关于「免费」和「数据」

这两点我说死：

- **纯本地处理。** 这个扩展没有任何后端服务器，不收任何数据，不上传任何东西。所有转换都在你自己的浏览器里完成。代码是 MIT 开源的，你可以自己审。
- **完全免费。** 没有会员、没有付费解锁、没有广告。就一个功能，做好就完了。

### 装上要多久

两分钟，三步：

1. 打开 GitHub 仓库，点绿色 `Code` → `Download ZIP`，解压
2. Chrome 地址栏输入 `chrome://extensions`，右上角打开「开发者模式」，点「加载已解压的扩展程序」，选中解压出来的 `src` 目录
3. 点图钉图标 Pin 到工具栏，收工

（对，它没上架商店。因为上架要交开发者费用、还要过审，我一个人维护，觉得没必要。手动加载一次就行，之后再也不管。）

### 一件小事

我修 PDF 排版的时候，被用户怼过一次。

他发来一份导出的 PDF，说：「你这导的是什么垃圾，一页有大半页是空的，图还是灰块。」

我量了一下：**单页最大空白 609pt，A4 整页才 842pt——等于 72% 的版面是空的，11 张图全部渲染成灰块。**

原因是我一开始把所有「不能拆」的元素都设成了 `break-inside: avoid`，一个大块在页底放不下，整块被推到下一页，上一页就空掉。

后来改成分层处理：代码块 avoid 但给高度上限，表格允许跨页但表头重复，图片 avoid 但限高。同时打印前逐张确认图片真的解码成功，失败的图直接压平。

改完再量：**最大空白 27.2pt，灰块 0 张。**

那之后我把这件事做成了自动化闸门——用真实 Chrome 打印，再用 PyMuPDF 量指标，超过阈值测试就红。现在有 68 项自动化测试在跑。

我不是想说这工具多厉害。只是觉得：**一个导出的动作，如果连排版都不对，那跟截图有什么区别。**

## 八、发布的注意事项

1. **前 3 行决定完读率**。正文开头「我先说一个我憋了很久的事」是钩子，不要删。
2. **图片顺序不要打乱**：封面 → 弹窗 → 三格式 → 数据 → 安装。第 4 张（72% 空白那张）是全篇最强的信任状，别放到最后。
3. **不要写「求关注」「求点赞」**。小红书对这类引导有降权，写「点个 star 就是最好的支持」更自然，也符合开源语境。
4. **正文里的 GitHub 链接**：小红书正文外链不可点击，但能被搜索识别。建议同时在**个人简介**里放一次，评论区再放一次纯文本。
5. **不要一次发多篇同类内容**。同一账号 48 小时内重复推同一个工具会被判营销号，间隔 5 天以上。
6. **数据要说准**：609.1pt / 27.2pt / 11 张 / 0 张 / 68 项测试，这些都是仓库里可验证的，被质疑时能立刻拿出依据。不要为了标题效果改成「90%」「100 倍」这类无法核实的说法。
