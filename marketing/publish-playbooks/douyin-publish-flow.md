# 抖音图文草稿自动化 · 可执行流程

> **用途**：让 AI 在任意项目中，把「图片 + 标题 + 描述 + 话题」自动填进抖音创作者服务平台的图文草稿箱。
> **终点**：点「暂存离开」保存草稿。**永不点击「发布」**。
> **适用**：Chrome 已登录 `creator.douyin.com`，Windows 环境。
>
> 本文档自包含，可直接投喂给 AI 执行。最后验证：2026-11，抖音创作服务平台 + Chrome 160。
> 底层代码与小红书版共用：`uiauto.py` / `forcefg.py` / `winlist.py`（见小红书文档附录）。
>
> **如果你已经跑过小红书那套，本文只需要读 §2（差异）和 §3（坐标标定）**，底层完全一样。

---

## 0. 给 AI 的执行摘要

```
1. 设 DPI 感知 → 找窗口 → 强前台
2. 导航到 /content/post/image    ← 不是 /upload！
3. 上传图片（文件对话框 + Win32 直写路径）
4. 填标题（y≈320，不是 210）
5. 填描述（y≈400）
6. 追加话题（Ctrl+End → 回车 → 逐个 #话题）
7. 按两次 End 滚到底 → 点「暂存离开」(1101,1300)
8. 确认跳回上传页 + 出现「你还有上次未发布的图文」
```

**四条铁律**：

- 标题框在 **y≈320**，y≈210 是「快速填写」按钮（最大的坑）
- 按钮在页面最底部，**必须先滚到底**
- 坐标必须现场标定
- 绝不点击「发布」

## 1. 与小红书版的差异（先看这个）

底层完全相同（DPI / 找窗口 / 强前台 / 剪贴板 / 文件对话框），只有这 6 处不同：

| 项目 | 小红书 | 抖音 |
| :--- | :--- | :--- |
| **发布页路由** | `/publish/publish?target=image` | `/content/post/image`（`/upload` 是视频页） |
| **标题框 y** | 405 | **320**（210 是「快速填写」按钮） |
| 上传入口 | 空态大按钮 (790,500) | 右侧区域 (1758,480) |
| **保存按钮** | (1066,1342) 直接可见 | (1101,1300)，**必须先滚到底** |
| **保存成功标志** | 顶部绿色「保存成功」 | 跳回上传页 + 「你还有上次未发布的图文」 |
| 标题与描述 | 分开两个框，各自独立 | 分开两个框，**都显示各自计数** |

抖音的标题和描述**分开计数**（20 / 1000），这点和小红书一样。

## 3. 坐标标定

### 参考坐标（2560×1440，DPI 96，窗口最大化 rect=(-8,-8,2568,1400)）

| 元素 | 坐标 | 说明 |
| :--- | ---: | :--- |
| 上传区（右侧） | (1758, 480) | 「点击上传」文字处 |
| **标题框** | **(1100, 320)** | 「添加作品标题」文字行 |
| 描述框 | (1180, 400) | 「添加作品描述」内部 |
| 暂存离开（**滚到底后**） | (1101, 1300) | |
| 发布（**禁用**） | (954, 1300) | 绝不点击 |

### 标定技巧：裁剪 + 比例换算

抖音页面元素密集，直接估算容易错。用裁剪放大来精确定位：

```python
from PIL import Image
# 裁出标题区域
Image.open("shot.png").crop((1010, 180, 1580, 330)).resize((1710, 450)).save("zoom.png")
```

然后在放大图里读占位文字的高度占比，换算回原图：

```
占位文字在裁剪图的 93% 高度处
原图 y = 180 + 0.93 × (330 - 180) ≈ 320
```

### 为什么 y=210 是陷阱

页面右上有个「快速填写」按钮在 y≈210，标题框在它下方 y≈320。一直点 210 当然填不进标题——而且页面**不会报错**，只是什么都没发生。

## 4. 执行流程

### 4.1 导航

```python
URL = "https://creator.douyin.com/creator-micro/content/post/image"
hotkey("ctrl", "l"); paste(URL); press("enter"); sleep(8)
```

⚠️ 点顶部「发布图文」标签**不会**跳转到图文页，必须直接访问 URL。
⚠️ `/content/upload` 是**视频**上传页，不是图文。

### 4.2 上传图片

与小红书相同的文件对话框方案：

```python
UPLOAD_ZONE = (1758, 480)
move(*UPLOAD_ZONE); click(); sleep(2)

dlg = FindWindowW("#32770", "打开") or FindWindowW("#32770", None)
edits = enum_children(dlg, "Edit")
SendMessageW(edits[0], WM_SETTEXT, 0, ctypes.cast(buf, ctypes.c_void_p),
             " ".join(f'"{p}"' for p in paths))
assert paths[-1].split("\\")[-1] in get_text(edits[0])

for b in enum_children(dlg, "Button"):
    if "打开" in get_text(b, 64):
        SendMessageW(b, BM_CLICK, 0, None)
        break

sleep(16)   # 抖音上传稍慢，等久一点
```

**验证判据**：页面显示「已添加 N 张图片」，缩略图栏出现所有图。

### 4.3 填标题

```python
TITLE_BOX = (1100, 320)
move(*TITLE_BOX); click(); sleep(1.6)
set_clipboard(TITLE); sleep(0.5)
hotkey("ctrl", "v"); sleep(2.0)
screenshot("verify_title.png")
```

**验证判据**：标题框显示文字 + 右侧计数从 `0/20` 变成 `n/20`。

### 4.4 填描述

```python
DESC_BOX = (1180, 400)
move(*DESC_BOX); click(); sleep(1.4)
set_clipboard(BODY); sleep(0.5)
hotkey("ctrl", "v"); sleep(3.0)
screenshot("verify_desc.png")
```

**验证判据**：底部计数从 `0/1000` 变成 `n/1000`。

### 4.5 追加话题

```python
DESC_END = (1180, 400)
move(*DESC_END); click(); sleep(1.4)
hotkey("ctrl", "end"); sleep(1.0)   # 到文末
press("enter"); sleep(0.5)

for tag in TAGS:
    set_clipboard("#" + tag); sleep(0.45)
    hotkey("ctrl", "v"); sleep(1.5)
    press("enter"); sleep(0.9)      # 选中下拉第一项
```

话题占描述字数（上限 1000）。正文控制在 950 字内。

### 4.6 保存草稿（**必须先滚到底**）

```python
click(700, 1200)     # 点空白让页面获得滚动焦点
press("end"); sleep(1.0)
press("end"); sleep(1.5)     # 按两次

# 此时按钮才出现在视口内
SAVE_BTN = (1101, 1300)
move(*SAVE_BTN); sleep(0.35)
click(*SAVE_BTN); sleep(6.0)
```

**验证判据**：页面**跳回上传页** + 顶部显示：

```
⚠ 你还有上次未发布的图文，是否继续编辑？   [继续编辑] [放弃]
```

看到这行就说明草稿已保存。**注意**：抖音保存成功没有绿色 toast，只能靠这个跳转判断。

## 5. 内容适配

| 字段 | 上限 | 注意事项 |
| :--- | :--- | :--- |
| 标题 | 20 字 | 比小红书更常被压缩，建议 12–16 字 |
| 描述 | 1000 字 | **话题也算在内**，正文控制 950 字内 |
| 话题 | 不限个数，受字数限制 | 抖音话题比小红书更容易命中流量池 |
| 图片 | 35 张 | 3:4 比例推荐 |

抖音标题更短更口语化，去掉书名号、破折号等装饰符号效果更好。

## 7. 失败 → 修法速查

| 症状 | 原因 | 修法 |
| :--- | :--- | :--- |
| 标题怎么都填不进 | 点在 y≈210 的「快速填写」按钮上 | 改到 **y≈320** |
| 进了视频上传页 | 用了 `/upload` 路由 | 改成 `/post/image` |
| 找不到保存按钮 | 页面没滚到底 | 点空白后按两次 `End` |
| 保存后没看到绿色提示 | 抖音本来就没有 | 看是否跳回上传页 |
| 上传区点击没反应 | 坐标偏了 | 左右两侧布局不同，重新标定 x |
| 描述被清空 | 用了 `Ctrl+A` | 抖音的 `Ctrl+A` 会**全选整个页面**，别用 |
| 点「继续编辑」进了 AI 工坊 | 坐标偏到旁边的按钮 | 「继续编辑」在 (1479,149)，注意核对 |
| 位置权限弹窗挡页面 | 浏览器权限询问 | 按 `Esc` 关闭 |
| 焦点反复被抢 | 同窗口其他标签 | 用 `--app=URL` 开独立窗口 |

## 8. 需要的手动前置

1. Chrome 必须在**同一台机器**上已登录抖音创作服务平台
2. 如果窗口关掉了，AI 可以导航，但**登录态需要用户自己确认**
3. 图片文件必须已经生成好，路径明确

## 9. 常见页面元素干扰（抖音特有）

| 元素 | 位置 | 处理 |
| :--- | :--- | :--- |
| 位置权限询问弹窗 | 左上 | `Esc` 关闭 |
| 「快速填写」按钮 | (1517, 172) 附近 | **别点**，会干扰标题定位 |
| AI 工坊横幅 | 顶部 | 别误点，会离开编辑页 |
| 剪映广告 | 页面中部 | 别误点 |
| 「清空并重新上传」 | 右侧 (1738, 848) | 别误点，会清掉所有图 |
